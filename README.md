# Bank Customer Churn Analysis

Analyzed a 10,000-customer bank dataset in Excel to identify churn drivers.

## What I did
- Cleaned and prepared the data using Power Query
- Built 11 pivot table reports breaking down churn by country, gender, age, credit score, products, and balance
- Designed an interactive dashboard with dynamic slicers for real-time filtering

## Key findings
- Germany showed a significantly higher churn rate than France or Spain
- Customers with 3-4 products had the strongest churn signal
- Churned customers had higher average balances than retained customers

## Tools
Excel, Power Query, Pivot Tables, Data Visualization
